## 项目中遇到的一些难以解决的问题。。

### 1.在elementui表格 单元格上打标签（如图所示）

![image-20230407170305012](C:\Users\21025\AppData\Roaming\Typora\typora-user-images\image-20230407170305012.png)

​	我使用的解决方法

```js
// 项目中 table组件是自己封装的，渲染数据使用render函数
<TableList
   :columns="columns"
   :data="tableData"
   v-if="tableData"
/>

··· js ···
/**
	使用定位解决，
	h生成一个div包含 tag组件和span文字
	使用父相子绝，具体数值根据自己业务来做调整
	isRequireTag属性，是去源文件更改table当前的cell添加class样式，将overflow设置为inherit,这样就可以让tag完整显示
	设置Zindex原因是 列与列之间也会遮挡tag组件，需要让tag组件权重变大不被影响。
*/
columns: [
   {
      prop: 'tblName',
      label: '表名',
      align: 'left',
      width: 340,
      isRequireTag: 1, // * 当前单元格需要打标签 放置属性
      render: (h, data) => {
      // * 去判断当前表是否已停更
      if(data.row.stopUpdated === 1){
          return h('div',{
            style:{position:'relative'},
          },[h('el-tag',{
            props: {type: "danger",size: 'mini',color:'rgba(255,0,0,0.6)'},
            style: {
               padding: '2px 14px',
               position:'absolute',
               display: 'block',
               transform: `rotate(30deg)`,
               left: '-35px',
               top: '-2px',
               zIndex:'6',
               color:'#fff',
               height: '25px',
              },
             },'停更'),
            h('span',{},data.row.tblName)])
            }else{
              return h('span',{},data.row.tblName)
            }
          },
        },
]
```
