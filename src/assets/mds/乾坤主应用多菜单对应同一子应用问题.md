## 乾坤

#### Q：主应用的两个同级菜单分别对应同一个子应用的两个路径，第一个子应用页面显示正常，第二个就无法显示

##### 问题复现：

```typescript
// 子应用 - 路由表配置 - 
// 没有统一的父级菜单路由 子应用系统路由平铺
 {
    path: "/",
    name: "Index",
    redirect: "capital",
    meta: { hidden: true },
 },
 {
    path: "/capital",
    name: "Capital",
    redirect: "/capital/fund-balance-detail",
    component: () =>
      import(/* webpackChunkName: "layout" */ "@/layout/index.vue"),
    meta: {
      title: "账户余额报表",
      icon: "Home5Filled",
      role: "FundBalanceDetail",
    },
    children: [ ... ],
 },
 {
    path: "/capital/fundChannel",
    name: "FundChannel",
    redirect: "/capital/fundChannel/fund-ccb-error-tackle",
    component: () =>
      import(/* webpackChunkName: "layout" */ "@/layout/index.vue"),
    meta: {
      title: "资金通道",
      icon: "Home5Filled",
    },       
    children: [ ... ],
 }

```

```typescript
// 主应用 - 路由表配置	route.js
// 两个菜单对应同一子应用，没有统一父级路由包裹
{
  name: 'capital',
  path: '/capital/*',
  alwaysShow: true,
  meta: { title: '资金余额管理', icon: 'el-icon-tickets', role: '/capital' },
  component: () => import('@/layout/SingleQiankun.vue'),
  children: [ ... ], 
},
{
  name: 'fundChannel',
  path: '/capital/fundChannel',
  alwaysShow: true,
  meta: { title: '资金通道', icon: 'el-icon-tickets'},
  component: { ...EmptyRoute, name: 'FundChannel' },
  children: [ ... ], // children组件使用 import('@/layout/SingleQiankun.vue'),
}
             
// 主应用 - 注册子应用文件 micro-app.js
const microApps = [
 {
    name: 'capital-report',
    entry: `/capital/`,
    // 如果想在本地调试子应用，可以将此entry放开，7777 是子应用固定端口
    // entry: `http://localhost:7777`,
    activeRule: '/#/capital',
    container: SINGLE_QIANKUN_CONTAINER,
 },
]
```

##### 主要改动点：

1、主应用注册这个路由时给 `path` 加一个 `*`，对应 `path: '/capital/*'`,

2、必须保证微应用加载时主应用这个路由页面也加载了，component组件使用挂载容器的组件，对应`component: () => import('@/layout/SingleQiankun.vue'),`

**注意：如果这个路由有其他子路由，需要另外注册一个路由(对应同级菜单)，仍然使用这个组件即可**。
